# Herme Iuris

**El derecho explicado para todos.**

Herme Iuris es un sitio web informativo que busca acercar el derecho a personas sin formación jurídica: noticias y fallos explicados en lenguaje simple, glosario, cursos, jurisprudencia, un foro de la comunidad y un asistente legal.

🌐 **Sitio publicado:** https://sheilawayar.github.io/HermeIuris/

> ⚠️ El contenido del sitio es orientativo y no constituye asesoramiento legal.

---

## Secciones

| Sección | Descripción |
| --- | --- |
| **Home** | Presentación, áreas del derecho y formulario de consulta |
| **Actualidad** | Fallos y noticias con análisis jurídico desplegable y comentarios |
| **Foro** | Debates de la comunidad por categoría |
| **Mi Cuenta** | Perfil de usuario, estadísticas y configuración |
| **Cursos** | Catálogo de cursos por nivel (básico, intermedio, avanzado) |
| **Terminología** | Glosario jurídico con buscador |
| **Chatbot Legal** | Asistente con preguntas frecuentes |
| **Jurisprudencia** | Fallos nacionales y provinciales con búsqueda por tema o materia |
| **Buscador** | Acceso general a todas las secciones |
